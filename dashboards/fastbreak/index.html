Admin Tools

Set / Update a Day's Objectives

Saves to the league + mode selected in the picker above. Weight is computed automatically from the share of players projected to clear 100% of each objective's target (the rarer feat carries more weight).

Load Real Projections (Rotowire-sourced)

Projections are stored per league and date and shared by that league's Classic and Pro (a player's projected PTS doesn't depend on the mode), so one upload covers both. Pasting a full Rotowire table captures every stat column it recognizes in one save. Any stat with no uploaded projection for a date shows Proj as TBD, except PITP, which always falls back to the L10 average automatically (neither Rotowire nor standard sites project it).

Rebuild a Day's Data

Each league/date's live data is cached for 10 minutes (6 hours for past dates). Use this after a roster move, or after adding PITP to a day that didn't have it, to force the next load to re-pull from BALLDONTLIE.

Set / Update a Historic Day's Objectives

Historic is keyed by day number (Day 1, Day 2, ...), not calendar date. The date label is optional and only used for display.

Historic Data Upload (players / schedule / objectives)

Paste a JSON object with any of the keys players, schedule, objectives (the build_players / build_schedule / build_objectives output). Each key you include replaces that dataset in full; keys you leave out are untouched. "Seed from repo files" loads the three JSON files checked into the repo's historic-seed/ folder instead of pasting.

Advance the Historic Season

Simulates the next day's box scores and moves the public "current day" pointer forward. Never re-rolls a day that's already been simulated. Nothing advances automatically until you decide the season is running.
