Load Real Projections (Rotowire-sourced)

BALLDONTLIE has no projections endpoint, so Proj values for most objectives come from here -- a manual, Rotowire-sourced upload. Pasting a full Rotowire table captures every stat column it recognizes in one save (so both objectives on a two-objective day are covered by a single paste, no need to change Stat and resubmit). Any stat with no uploaded projection for a date shows Proj as TBD, except PITP, which always falls back to the L10 average automatically (neither Rotowire nor standard sites project it).
